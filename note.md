Landing a fix can now close specific registered bugs automatically via `Fixes-Bug: <id>` commit trailers (or `land --fixes <id>`), and `land bug resolve <id> --by <fix-sha>` closes bugs whose fix already landed. `land bug` and `land bugs` now show each bug's short id, and bug-specific repairs target individual bugs instead of closing every bug on a culprit commit. Releases `0.12.0`.
